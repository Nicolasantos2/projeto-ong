# Projeto ONG

Projeto front-end acadêmico desenvolvido para uma ONG, com páginas de apresentação, projetos sociais e cadastro.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Git/GitHub
- GitHub Pages

## Funcionalidades
- Navegação entre páginas
- Menu responsivo
- Projetos gerados com JavaScript
- Formulário com validação
- Persistência com localStorage
- CSS Grid e Flexbox
- Estrutura semântica e recursos de acessibilidade

## Estrutura
- `index.html`
- `projetos.html`
- `cadastro.html`
- `css/`
- `js/`
- `imagens/`

## Publicação
O projeto pode ser publicado pelo GitHub Pages a partir da branch `main`.
